## 🧭 How I Work

- **I learn by building.** I pick a real idea, start making it, and learn each new thing when the project needs it.
- **I use AI as a helper, not a shortcut.** AI speeds up my work, but I make sure I understand what I'm building before I move on.
- **I start simple and improve.** First a working version, then better design, features and cleaner code.
- **I share my work publicly.** An idea sitting on my laptop helps nobody, so I put my projects on GitHub and keep improving them.
